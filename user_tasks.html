Project: Lets Discuss • User Stories US-01 to US-10 • Laravel API + React SPA

Planning assumptions (please confirm or correct)

  • Stack: Laravel 13 + Sanctum SPA cookie auth + PostgreSQL; React + TypeScript + Ant Design + TanStack Query + Zustand; spatie/medialibrary on MinIO; Cloudflare Turnstile for captcha; PHPUnit and Vitest/React Testing Library for tests (per the project initialization design).
  • RBAC: the spec leaves "enum + policies vs spatie/laravel-permission" open. These tasks assume a role enum on users plus Laravel policies. Guest is not a stored role.
  • Shared schema: the posts migration (T05.1) already includes visibility and comments_enabled so US-09 and US-10 need no table rewrites.
  • "Restricted" (US-09): assumed visible to the author, an explicit allow-list of users, and Admins. Needs your confirmation.
  • Revoking Verified (US-04): existing restricted posts and owned groups are kept, but the user can no longer create new restricted posts or groups. Needs your confirmation.
  • Guests (US-05): text only, no images, always public. Image upload is for registered users (US-07).
  • Out of scope here: XSS sanitization (US-40), CSP (US-39), rate limiting (US-48), feed queries (US-30/31) and post edit/delete (US-12/13). Tasks leave hooks for them.
  • Estimates are rough single-developer hours, including self-review. Every API task includes its OpenAPI update or has a matching docs task.
